## 功能差异明细

作为**通用基线**：无衡水 HIS ID 强制、无枣强主数据禁止新增、无众阳推送、无衡水计费自动消耗；出入库打印走默认 Hs 入口分支中的非枣强路径。

| 功能域 | 行为 |
|--------|------|
| 主数据 | 可手工维护（常规校验） |
| 耗材编码 | 留空可自动生成 6 位数字，可手工输入 |
| 仓储 | 出库后不自动收货（除非后续单独配置进租户集合） |
| 打印 | 非 `*PrintZq` |
| HIS | 无专用集成登记 |

后续若某医院按「默认」部署，差异需求应**新建正式 TenantEnum**，不要直接在 DEFAULT 上堆生产特例。
