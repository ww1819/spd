# SPD 租户文档总入口

权威枚举：`spd/spd-common/.../TenantEnum.java`

## 怎么用（两种文档）

| 文档类型 | 写什么 | Agent 怎么改 |
|----------|--------|--------------|
| **[总览-共性需求与问题.md](./总览-共性需求与问题.md)** | 所有租户都要改的共性问题、共性需求、整体改造记录 | 改**共享**代码/页面，行为对全部租户生效（或明确列出的多个租户） |
| **各租户「需求与问题.md」** | 仅该医院的需求、缺陷、验收问题 | **只改该租户**；必要时拆独立前端页，互不影响 |

## 租户文档（单独一份，只改本租户）

| 租户 | 枚举 / customerId | 在此输入需求与问题 |

| 枣强县中医院 | `ZQ_TCM` / `zaoqiang-tcm-001` | [ZQ_TCM…/需求与问题.md](./ZQ_TCM-枣强县中医院/需求与问题.md) |

每个租户目录另有 `FEATURES.md`（已实现差异说明，供对照，一般不用手写需求）。

## 判断写到哪

- 「只有衡水要这样」→ 衡水 `需求与问题.md`
- 「只有枣强要这样」→ 枣强 `需求与问题.md`
- 「所有医院都要 / 公共 bug / 公共交互」→ **总览-共性需求与问题.md**
- 拿不准 → 先写总览，并注明「可能仅某租户」，Agent 实现前再确认

## 功能差异对照（生产租户）

| 功能域 | 默认/通用 | 衡水 `HS_003` | 枣强 `ZQ_TCM` |
|--------|-----------|---------------|---------------|
| 科室/供应商/厂家 | 可手工新增 | 须填 HIS ID | 禁止手工，HIS 同步 |
| 耗材档案 | 编码可手填/自动 | GZ/DZ/SJ+5 位系统生成 | 禁止新增；已有仅可改分类/厂家/供应商/单价 |
| 入/出库申请 | 走独立审核菜单 | 同默认 | 弹窗内可直接审核 |
| 出库审核后 | 手动收货 | 自动收货 | 自动收货 |
| 打印 | Hs 版式 | `*PrintHs` | `*PrintZq` |
| 众阳 HIS 推送 | 否 | 否 | 是 |
| HIS 计费镜像/自动消耗 | 否 | 是 | 否 |
